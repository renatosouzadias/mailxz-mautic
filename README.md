# mailxz-mautic

Imagem Docker customizada da **Mail XZ** — Mautic 4.4 (base oficial `mautic/mautic:v4-apache`) com as personalizações da plataforma baixadas por cima.

- Publicada em `ghcr.io/renatosouzadias/mailxz-mautic:v4.4.12`
- Build automático via GitHub Actions a cada push na `main`.
- Personalizações atuais: injeção do widget de uso (barra de leads/disparos vs. plano) no admin.

> Versão do Mautic fixada de propósito. Para atualizar, mudar a base no Dockerfile e criar uma nova tag.
